# 管理员菜单权限刷新缺陷修复记录

> 版本：v1.0 | 日期：2026-07-26 | 状态：已修复

## 用户需求

修复切换登录管理员账号后，侧栏菜单未及时显示该账号应有权限的问题，并推送代码。

## 根因与证据

`App.vue` 使用 Vue `computed` 直接读取 `localStorage` 中的登录用户。`localStorage` 不是响应式数据源，账号切换写入新用户后不会使该计算属性失效，页面外壳复用时仍可能显示上一账号的菜单权限。

## 已完成修改

- 新增前端认证会话模块，以 Vue `ref` 作为当前用户的响应式单一来源，并继续持久化 token 与用户信息。
- 登录成功时通过会话模块同步更新存储和响应式用户。
- 退出登录及修改密码后统一清空会话，确保普通账号与管理员账号双向切换时菜单均立即刷新。
- 侧栏管理员菜单改为依赖响应式当前用户的 `ADMIN` 角色。

## 影响范围与风险

影响 `build/web` 的登录、退出、修改密码和侧栏权限展示，不改变后端鉴权或路由守卫规则。主要风险是浏览器中存在损坏的历史用户数据；会话模块对此进行容错并清除无效数据。

## 验证

执行前端生产构建，确认 TypeScript 与 Vite 编译通过。人工验收建议依次使用普通账号、管理员账号、普通账号登录，确认“企业微信设置”和“账号管理”菜单按角色即时隐藏、显示、隐藏。
